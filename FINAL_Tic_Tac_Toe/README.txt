WEB114 Final – Pokémon Tic-Tac-Toe
Dylan Gregory  12-08-2025

This project is a Pokémon-themed Tic-Tac-Toe web game. I chose this project because I enjoy Pokémon and 
wanted to build a fun and interactive browser game. 

JavaScript is used to track game state, detect wins, reset the board, switch turns, and show a mode selection 
screen. I used variables, arrays, event listeners, custom functions, if/else logic, comparison operators, 
Math.random(), and DOM manipulation to update text and images on each turn. The game includes Player vs 
Player or Player vs CPU mode and displays Pokémon icons instead of Xs and Os.

To start a new game, choose a mode, click a square to play, and restart or return Home at any time.
